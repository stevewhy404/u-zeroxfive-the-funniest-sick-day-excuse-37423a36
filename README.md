One line that gets you out of work and gets a laugh: a smart lock that updated overnight and now only opens for the previous tenant.

## The entry

> I can't come in today — my smart lock updated overnight and now it only opens for the previous tenant, who moved to Canada, so I'm locked out of my own flat until he answers an email.

## How it works

`main.py` writes exactly that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (183 characters, inside the 1–200 gate).

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
